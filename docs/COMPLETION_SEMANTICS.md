# 补全语义与排序权重

## 1. 输入与光标

请求由 `uri` 与零基 `Position(line, character)` 组成。位置通过对应提交版本的
不可变 `LineIndex` 转换为绝对偏移；越界位置被确定性地收敛到合法边界，不会
抛异常。光标左侧紧邻的标识符片段作为**前缀**（prefix）。

## 2. 候选类别

- `LOCAL_VARIABLE` 局部变量（含 `for` 头变量、`var` 声明）
- `PARAMETER` 方法参数
- `FIELD` 类型成员字段
- `METHOD` 方法（含构造器）
- `TYPE` 类 / 接口 / 枚举 / 记录
- `KEYWORD` 关键字

候选只包含**当前作用域链上可见**的符号，加上上下文允许的关键字：

- 普通位置：从最内层作用域向外收集可见符号（应用遮蔽），再加关键字；
- `qualifier.` 成员访问：只收集 `qualifier` 已解析类型的字段/方法以及
  `this`/`super`，绝不会退回为整份文档的符号全集；
- 候选必须以前缀开头（区分大小写）。

### 作用域与遮蔽

- 作用域以花括号为物理边界（文件、类型体、方法体、普通块、`for` 头）；
- 符号只在其声明名位置之后可见（声明之前不可见）；
- 同名符号内层遮蔽外层；按名称去重时保留**最内层、类别更强**的那一项，
  同时在 `source` 中保留所有来源（`local@偏移`、`parameter@偏移`、
  `field@偏移`、`method@偏移`、`type@偏移`、`keyword`）。

### 容错

解析器是“恢复式”的：

- 未闭合的块在 EOF 处闭合，补全仍有确定的最内层作用域；
- 意外 token 只前进一个字符并记录到 `errors`，不抛出；
- 未闭合字符串/块注释运行到 EOF；
- 因此语法错误或未闭合块也返回确定结果，而不是整段放弃或返回无关全集。

## 3. 去重与稳定排序

候选按 `label`（即插入文本/名称）去重。最终排序为：

1. 分数从高到低；
2. 分数完全相同时按 `sortText = 类别序号|名称`；
3. 再按 `label` 兜底。

因此同一文档、同一光标、同一配置下多次请求逐项一致（测试
`CompletionSemanticsTest#deterministicOrder` 等覆盖）。

## 4. 分数构成

```
score = 类别基础分
      + proximityWeight * 邻近层级
      + typeMatchWeight  * 类型匹配(0/1)
      + recencyWeight    * 最近编辑衰减
```

- **类别基础分**：见 `CONFIGURATION.md`（局部变量 > 参数 > 字段 > 方法 >
  类型 > 关键字）。
- **邻近层级**：符号声明所在作用域距光标作用域的层数，越近越高。
- **类型匹配**：在能保守推断出期望类型时（如 `Type x = |`、
  `return |`、已声明局部/字段的类型）加满分；推断不出则为 0，绝不臆造。
- **最近编辑**：编辑命中的符号进入有界的“最近编辑”窗口；最近一批加分
  `recencyWeight`，越旧线性衰减到 0。最近编辑状态随快照持久化，重启后
  分数仍可复现（按批次序列化，而不是仅存去重名称）。

`scoreReason` 以可读字符串给出每一项的加分拆解，`sortText` 给出确定性的
并列次序。

## 5. 期望类型推断（保守）

- `Type name = |`：期望类型取左侧声明类型的简单名；
- `return |`：取最近方法签名的返回类型（尽力推断）；
- 成员补全使用限定符符号的声明类型定位其类型体。

推断不到时不加分、也不产生错误候选。
